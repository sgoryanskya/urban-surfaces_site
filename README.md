# Городские покрытия — сайт

Статический сайт компании «Городские покрытия»: устройство резиновых и водопроницаемых покрытий в Москве и Московской области. Сборка и сервер не нужны. Достаточно положить файлы на любой хостинг статических сайтов.

## Что в папке

```
index.html             разметка всех страниц и небольшие скрипты интерфейса
assets/css/site.css    стили (шрифт Golos Text встроен внутрь)
assets/js/scene.js     3D: образцы покрытий, этапы работ, первый экран (three.js r165, MIT)
assets/img/            фото и иллюстрации в WebP
```

Страницы переключаются без перезагрузки, адреса вида `#/pokrytiya`, `#/obekty`, `#/o-kompanii`, `#/kontakty`. Поэтому отдельные HTML-файлы для страниц не нужны.

## Как посмотреть

Откройте `index.html` двойным щелчком: сайт работает и с диска.

Чтобы проверить его как на хостинге, запустите в этой папке локальный сервер и откройте http://localhost:8000:

```bash
python3 -m http.server 8000
```

## Как добавить в git

В Терминале перейдите в папку сайта:

```bash
cd ~/Documents/ГП/gorodskie-pokrytiya-site
```

Создайте репозиторий и первый коммит:

```bash
git init
git add .
git commit -m "Сайт «Городские покрытия»"
```

Создайте пустой репозиторий на GitHub (или в GitLab) и привяжите его. Вместо `АДРЕС` подставьте ссылку на репозиторий:

```bash
git branch -M main
git remote add origin АДРЕС
git push -u origin main
```

## Как опубликовать

**GitHub Pages:** в репозитории откройте Settings → Pages, в разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Через минуту-две сайт будет доступен по ссылке, которую покажет GitHub.

Подойдёт и любой другой хостинг статики: Netlify, Vercel, Яндекс Object Storage, обычный хостинг с FTP. Загрузите содержимое папки как есть.

## Приём заявок

Пока адрес приёма заявок не указан, кнопка формы открывает почту посетителя с готовым письмом на office@gorodskie-pokrytiya.ru.

Чтобы заявки приходили в CRM, сервис форм или на сервер, найдите в `index.html` комментарий «ОТПРАВКА ЗАЯВКИ» и впишите адрес в строку:

```js
var FORM_ENDPOINT = '';
```

Туда уходит POST-запрос с полями формы: `form`, `type`, `coat`, `address`, `area`, `name`, `phone`. Состояния «Отправляем…», ошибка с повтором и «нет интернета» уже готовы.

## Где что менять

- **Тексты** — в `index.html`.
- **Цвета, отступы, шрифты** — в `assets/css/site.css`. Цвета заданы переменными в начале файла (`--ink-…`, `--blue-…`).
- **Фото** — в `assets/img/`. Новые фото лучше сохранять в WebP шириной не больше 2000 px.
- **Исходники фонов** первых экранов и баннеров лежат в папке «ГП/Фоны первых экранов».

## Однофайловая версия

Рядом с этой папкой лежит «Городские покрытия — сайт.html». Это тот же сайт одним файлом: все стили, скрипты и фото встроены внутрь. Его удобно отправить заказчику на просмотр. Для git и публикации лучше эта папка: фото здесь отдельными файлами и грузятся по мере прокрутки.
